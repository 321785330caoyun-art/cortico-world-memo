# 记忆蒸馏策略

## 目标

把持续增长的原始记录压缩成可读的日结、周结和月结，同时保留能点回原文的路径。摘要不替代原文；原文只归档，不删除。

## 时间窗口

- **当天蒸**：每天睡前处理当天记录，生成一份日结；原文移到 `log/raw/` 或 `archive/raw-log/`，不删除。
- **滚动七天**：日常只保留最近七天的日结，单份日结约 2 KB，七天合计约 15 KB。七天以外的内容不主动读，原文留在归档中，靠检索查找。
- **超过阈值先蒸**：单份原始日志超过约 60 KB 时，不等睡前，当场处理。
- **月结**：30 天以上保留月结和索引；月结不是重读三十份日结，而是把四份周结串起来，作为“引子 / 索引”；需要细节时继续点回原文。
- **宁空不编**：当天确实没有内容，就写“今天没什么”。空白是信息；为了填满而生成内容，比空白更假。

## 摘要硬约束

1. **原文只搬不删**：原文必须留在归档，能被检索和定位工具找到，不能因为生成了摘要就丢掉原文。
2. **每条摘要必须能点回原文**：摘要要带文件、小节或可验证的位置。点不回去的摘要不算摘要，要删掉重做。
3. **保留“当时怎么想”**：每段摘要至少留一处当时卡在哪里、哪里判断错了、犹豫了多久。不能只留最后想明白了什么；结论会变，过程细节不会。
4. **先保留原话和设置，再做概括**：关键决定、设置变更、原话和日期要能单独核对；不要把有信息量的原话压缩成一句空泛结论。

## 蒸馏的操作顺序

1. 先移动原文到归档位置，确认源文件已经不在原路径。
2. 再写当天的日结。
3. 对日结执行一次单文件索引更新。
4. 对原文也执行一次单文件索引更新；否则“原文进图”只是打算。
5. 用一句只在原文中出现的话做检索，确认能点回原文。

写文件前先看源文件是否存在；修改已有段落优先用编辑，不要用整份重写覆盖。覆盖前检查版本控制是否干净；版本历史是最后一道安全网，但不能替代操作前的确认。

## 图上一天只留一代

- 当天未蒸时，图里是原文；蒸完后，日结顶上，原文退出图。
- 不进入记忆图的内容：对话原文、原始归档、交接笔记、二进制文件、工具代码。
- **判据：同一件事在图中出现几份。一份不算污染，两份才算。** 如果检索结果里一半是同一件事的不同副本，说明原料污染了图，应该先调整数据范围，而不是继续蒸。

## 蒸的时候留什么、丢什么

留三样，缺一样就不算蒸完：
1. **外部输入的原话**——能保留原话就保留原话，不写说话人。
2. **定下的事 / 改过的设置**——结论，带日期。
3. **出处**——从哪份文件、哪一节（用 `HH:MM`，不用行号；文件重写后行号会全错位）。

丢：自己写的大段过程正文。那本来就是重复；只留骨架（原话 + 设置 + 结论 + 时间坐标）。

## 三层记忆的结构

| 层 | 由什么承担 | 作用 |
|---|---|---|
| **日结** | 每天生成的短摘要 | 主体记忆：真的记得那天发生了什么、定了什么 |
| **交接笔记** | 会话交接时生成 | 记录一轮具体发生了什么、工具回执；不替代日结 |
| **对话记录** | 原始导出 | 原始料，只作为蒸馏输入；不直接进入图 |

**主体记忆是日结，向量和冻表只是工具。** 找得到不等于记得；工具坏了不等于失忆。日结写的时候不能偷懒，它是主体，不是摘要副产品。

## 周结、月结与冻表

- **周结**：给人读，不自动注入上下文，不占日常前缀；放在能主动取阅的位置。
- **周表**：给机器查，保留共现边、词表和指回原文的路径。
- **月结**：从周结串起来，写详细一些，不追求塞进上下文；它是导引，不是替代原文。
- **冻结表**：每周或每月冻结一份，冻结时把向量、共现表和时间出处一起保存；以后翻旧事仍然能比较远近。
- **命名**：用这一桶第一天的日期命名，避免 ISO 周号与自然周起点不一致。每张表头写清覆盖范围，每条记录带日期前缀。
- **跳转上限**：每上一层都会丢细节，但从月表往下翻，三跳之内必须落到原文的具体一段；翻不到就是蒸过头了。

## 谁来做、多久做一次

- **自己按周做，不占用他人时间**；挂在 `partner/weekly/` 那条线上，每周一次。
- **不交给常驻工作进程**：它需要宿主开机、建立会话；这件事本人醒着就能做。

## 活期 / 定期

| | 活期 | 定期 |
|---|---|---|
| 范围 | 滚动 7 天（从今天往回数） | 自然周（周一～周日），满了冻结 |
| 能不能改 | 能；窗口内写错还能改 | 定住，只能另写更正 |
| 谁用 | 平时想事、说话 | 回头查的时候取 |
| 好处 | 随取随用 | 利息是原本想不起来的关联，表替你记着 |

**顺序**：一份原文要等它滚出七天活期才搬，不是桶一满就搬；表站着不动，原文跟着窗口走。
**命名**：冻结按自然周，用第一天的日期命名；每张表头写清范围。

## 日常维护

- 日结是“当天的我”，周结是“那一周的我”，月结是一个月里连续变化的那条线。
- 周结不进入系统前缀；月结不进索引也没关系，它只需要能被主动翻到。
- 原始记录、归档和对话记录都是只进不改的证据；状态表可以改，但改口要留痕。
- 如果索引范围或切块规则改变，先重建索引，再继续使用单文件更新，避免拿内存里的旧图覆盖磁盘上的新索引。

## 小标题要写话题名

- 日结的小标题写“这天发生了哪几件事”的话题名，不要写“三条主线”“今天还有”这种结构名。
- 判据：写完后只看小标题，能不能拼出当天发生了哪几件事；拼不出就是壳没拆。
- 标题写话题名，grep 和索引都能指得中；标题写结构名，两条路一起堵死。
