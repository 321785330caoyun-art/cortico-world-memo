# 记忆分层：两条路一起走

## 核心判断

记忆系统有两条路，谁也替代不了谁：

- **向量/联想层**：解决“想不起该用什么词”。它只负责把可能相关的段落找出来。
- **笔记正本**：解决“是不是”。被找回的内容必须回到原文，由本人判断。

**召回返回的必须是一个能点开的位置**（文件、小节或行、写入时间），不是一段结论式摘要。点不开的候选不算有效记忆。

## 五层结构

```text
① 推送层  短身份 / 当前状态 / 固定规则，每轮都进，永远短
② 索引层  别名表、主题索引，查之前先扫
③ 正文层  笔记正文，可无限长，真正的事实在这里
④ 召回层  向量 / 图传播，想不起词时的钩子，只给候选位置
⑤ 原文层  = ③，召回最终必须落到正文的某一行
```

④ 和 ⑤ 之间的硬约束：**召回层不许自己出结论。**

## 四、真正要改的那件事，不是装软件

- `INDEX.md` 的“别的叫法”是这条路的穷人版；先把这一列写实。
- 如果别名叫法够用，向量可以不上；不够用再上。
- 顺序不能反：先上向量，就很难再回去把索引做实。

## 五、不新做，先改旧的

- 旧的实现即使能跑也不直接复用；判断标准不是“能运行”，是质量是否够。
- 这个方向已经被验证过，知道粗做会粗糙；新方案要比“有个能跑的”高一个档。
- 不因为“反正有现成的”把自己推回旧路。

## 上这一层之前必须满足的条件

1. **索引与笔记同源**：索引只能从笔记正文生成，不许有第二份真相；笔记改了要能重建，索引里有但笔记里找不到的条目视为不存在。
2. **召回带位置**：每条结果包含文件路径、小节或行号、写入时间；不要只给摘要。
3. **能关掉**：关掉召回层，仍然能靠索引、grep 和读原文工作；不能出现“只有召回层知道的东西”。
4. **保持明文**：笔记仍是 Markdown，不加密，不搬进不可读的数据库。
5. **先在旁边跑**：上新层前保留原样对照，先运行一段时间，好的留下，不好的换回去，不在唯一副本上直接替换。

## 工具契约

```text
memo_recall { query, k?, scopeFile?, scopeAnchor? }
  → { confidence: 'high'|'mid'|'low',
      text: '这里可能相关…' | '想不起，翻下本子',
      items: [{ file, anchor, writtenAt, snippet, why }] }

memo_grep   { query, limit? } → { hits: [...] }
memo_locate { file, anchor }  → { file, lines, text }
memo_link   { file }          → { ok, file, blocks, savedAt }
memo_index  { mode? }         → { scannedFiles, addedBlocks, droppedBlocks, durationMs, lastIndexedAt }
```

`scopeFile` 是笔记内相对路径，用来只查某一页；`scopeAnchor` 是小节标题/锚点，用来只查某一节，可以和 `scopeFile` 一起使用。两者都不传时，行为与普通查询一致。显式 scope 过滤后为空时，应明确返回范围兜底，不要把范围兜底说成全局分数提高。

**什么时候不能信表**：表是最后一次成功索引时的磁盘状态。之后新写的内容在下一次索引前不在表里；回执里的 `lastIndexedAt` 之后修改过的文件都可能尚未进入索引。

## 插件三件事：存、取、分门别类

- **存**：只追加、一个文件装一件事；新文件自动在 `INDEX.md` 挂一行；每次记一笔，顺手把位置写进当天流水。
- **取**：`grep` + `INDEX`（含“别的叫法”）；需要“什么时候去翻”的触发和“时间词/黑话怎么翻译”；返回原文位置，不给结论摘要。
- **分门别类**：最弱、最容易烂；分类必须自己写，不让引擎替你分类，否则本子会变成别人的抽屉。
- **顺序：先存后取**。取不出来多数不是没索引，是当初没写清“为什么、在哪”；先补位置回写，再谈触发。

## 分阶段实现

| 阶段 | 建什么 | 解决什么 | 不解决什么 |
|---|---|---|---|
| 一 | `blocks` + `graph`：共现边、时间箭头、带衰减传播 | “提过 A，也提过 B”可以顺着走到 B；两跳也能到 | 意思近但字面完全不重合时连不上 |
| 二 | `vectors` + 跨字面近邻边 | 字面不沾但语义接近的内容能互相到达 | 久远强关联与近日琐事谁该压过谁 |
| 三 | 双尺度场（近场 + 远场降采样融合）+ 增量索引 | 近事不淹没远事；长笔记不用频繁手动全量重建 | — |

**共现边是明线**：可靠、可解释、只认字面。**向量边是暗线**：跨字面，但可能连错。两者叠加，不是替代；传播时先走明线，走不到再借暗线跳一段。

第一期先不上向量，是为了先建立可靠的共现基线，才能判断一条暗线该不该信。向量模型推荐小而中文优化的模型，用低维、半精度存储；先确认实际规模和瓶颈，不把“上大模型”当成默认答案。

## 数据范围

- 纳入：`partner/**/*.md`、`log/**/*.md`。
- 排除：`handoffs/`（交接摘要，和正文重复）、`archive/`（被取代的旧版，会和新结论抢位置）、`blobs/`（二进制）、`tools/`（代码，用 grep 即可）。
- 为什么必须纳入 `log`：只扫 partner 会漏掉“今天怎么定的”这类只在日志里出现的事实。
- 为什么必须排除 handoffs/archive：它们是同一件事的旧说法和摘要；回忆要的是定稿，不是草稿。两份同时进图，会出现同一件事的两个版本。
- 块数只在“扫描范围固定”时可比；范围一变，旧数字作废，不要拿新旧块数直接比较。

## 切块原则

- 结构边界优先：一条消息、一个列表项、一个小节标题、一张表都算天然边界；先按结构切，切完是什么就是什么，不再只看字数。
- 字数只做兜底：只有切完仍超长且中间没有结构边界时才按句切；这种情况多，说明原文写法该改，不是切块器该继续加特判。
- 不要把“按路径特判”写进切块器；认行首形态，不认具体目录。
- 验收至少看：块数、块长中位数、超过 800 字且内部有至少两个结构边界的块数（应为 0）。

## 建边原则

当某个词挂在大量块上、两两边配对会爆炸时，不能按块 id 邻近开窗口。**id 邻近只说明文件和行号相邻，不说明语义相近**；按窗口压边数，压法是假的。

正确顺序：

1. **最长匹配**：同一段连续文字只保留最长的词，避免同一个名字的多个 n-gram 重复计入。
2. **边权用 IDF**：`w(边) = Σ 1 / log(1 + df(key))`；挂很多块的词贡献接近零，稀有词贡献更大。
3. **不要硬删高频词**：`df` 大的词只降权，不用“df > 块总数 × 2%”这种硬门槛删除；`df=1` 的词本来就不产生边。把“高频=背景词”的判定取消，保留低权比删除安全。
4. **per-block top-K**：对每个块，候选是所有与它共享至少一个 key 的块；分数为共享 key 的 IDF 之和，保留分数最高的 K 个（K=60，允许 40–60）。不要按 key 的 id 顺序取前 N，不要给每 key 设 pair 上限。
5. **有向选择、无向合并**：每块主动选出度 top-K=60；被选中的块可以成为很多块的邻居，入度超过 60 是正常的，不强制对称；高入度可能表示真枢纽。
6. **分批落盘**：按 key 处理完就 flush，不要一次把全部边攒在内存里。
7. 如果做完这些边数仍然撑不住，应报告并改方案，不能再用 id 窗口硬压。

**采样检查**：光看块数/边数/通过率看不出图有没有意义；要抽样检查权重最高的边连的是不是同一件事，并检查高度数块和零度块。

## 验收标准

1. 真实索引回执：文件数、块数、边数、耗时。
2. 随机抽 10 块反查，每一块都能点回原文的具体行。
3. 用真实存在的关联测试联想，必须能带出字面不重合但同段相关的结果；每条带文件、锚点、写入时间和片段。
4. 库外词、乱码、生造词必须返回 `low`，不许返回 `high`；没有证据就回答“想不起”。
5. 返回的片段里必须看得见命中的词；说命中了但片段看不见，等同于点不开。
6. 只给位置不给理由的传播结果不可靠；传播来的条目要说明经过哪条边、共享哪些词，纯噪音应剔除。
7. 试跑第一期的验收只看三件事：能点回原文、命中词在片段里可见、库里没有的必须承认没有。块切得漂亮不能替代这三件事。

## 一页验收 / 不做清单

**验收：**

1. 索引与笔记同源：图/表只能从笔记正文生成，笔记改了要能重建；图里有、笔记里找不到的条目视为不存在。
2. 召回带位置：每条返回文件 + 行号或小标题 + 写入时间；返回里不许出现结论句，只能说“这里可能相关”。
3. 能关：关掉这一层，仍然能靠 `INDEX` + `grep` + 读原文工作，不能出现“只有它知道的东西”。
4. 不动明文：笔记保持 Markdown 原样，图是派生物，存在别处。
5. 先单独跑：上新层前保留原样对照，跑一段看准不准，好的留、不好的换回去，不在唯一副本上直接替换。

**不做清单：**

1. 不自动往本子里写：联想不许直接落笔，必须确认。
2. 不替自己分类：自动分完就不知道东西去哪了。
3. 不把摘要当结论：摘要只能给位置，结论要回原文判断。
4. 不做每轮自动注入：先用“主动叫的工具”，自动只记录、不注入，观察稳了再谈。

## 错误、改口与安全

- 错误要留痕：旧判断旁边标 `⛔ 已推翻` 或 `✅ 已修正 → 新位置`，不要直接覆盖；状态表可以更新，历史记录只追加。
- 事实变化时，正本只保留一个当前值，并在原处保留“原以为 A → 后来是 B，因为 C”的痕迹。
- 作废段落要压短，只留“当时怎么打算 + 为什么后来不这么干”，详细推演放回原始日志。
- 派生索引是可删除、可重建的副产物；绝不把索引写回笔记正文、对话原文或交接笔记。
- 上线前先单独跑，保留原样对照；改动索引范围、切块规则或引擎后，先重建再继续使用单文件更新，避免旧图覆盖新索引。
