# 记忆工具怎么配合使用

## 五个工具

| 工具 | 管什么 | 什么时候用 | 返回什么 |
|---|---|---|---|
| `memo_grep` | 字面精确搜索 | 记得某句话里有某个词、某个数、某个名字 | 命中的行和上下文，带文件、行号 |
| `memo_recall` | 联想召回（向量 + 图传播） | 只有一句人话，不知道用什么词 | 最多 k 条候选，带文件、小节、行范围、片段、分数 |
| `memo_locate` | 点回原文 | 要引用、要判断、要改东西之前 | 那一段的逐字原文和行号范围 |
| `memo_link` | 把文件挂回记忆图 | 刚改完一个笔记文件 | 单文件重算并落盘；也可以查看邻居 |
| `memo_index` | 全库重建 / 载入 | 换切块规则、索引损坏、跨会话第一次 | `full` 重扫全库；`load` 只从磁盘载入 |

## 默认顺序

1. 想起词了 → `memo_grep`。最快，也最不会骗人。
2. 只有一句人话 → `memo_recall`，拿位置。
3. 拿到位置后，要说出去、要改东西、要下判断 → 一律先 `memo_locate` 点回原文；只是“想一下”的可以用片段。
4. 写完笔记 → `memo_link` 把那一个文件挂回去。

## 三档可信度

- **grep 命中 = “有这句话”**：证明字在那里，不证明上下文就是自己以为的那个。
- **recall 命中 = “大概在这附近”**：可能碎、可能错、可能被刚写的新内容抢答；分数在 0.5 附近尤其不要直接当结论。
- **locate 拿到的 = 原文**：只有这一档能拿去引用、能拿去改、能拿去回话。

一句话记法：**模糊的找人（recall），精确的找字（grep），落地的看原文（locate）。**

## 三个常见坑

1. **“指到了”不等于“看过了”**：合并后的召回可能直接给一整节，更容易误以为已经读过；要引用时仍然先 locate。
2. **改了切块规则、重建索引之后，不重启就执行 `memo_link`**：可能拿内存里的旧图整份覆盖磁盘上的新索引，而且不报错。先确认索引代际一致。
3. **grep 搜不到同义不同词**：先用 recall 找词，再拿找到的词去 grep。

## 当前参数示例

- 切块：按 `##` / `###` 小节合并，单块上限约 450 字。
- 可信度分档：`>= 0.57` 高，`>= 0.42` 中，`< 0.42` 才清空。
- 具体规则以当前配置和 `memo_index` 回执为准，不要凭记忆猜参数。
