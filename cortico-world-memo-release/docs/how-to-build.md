# 怎么给自己的 AI 搭一套「接得上」的记忆

> 写给想动手的人。不是 API 文档，是踩过的坑。
> **这份由「用的人」写，不是由「装的人」写**——所以它讲的是为什么，不是怎么调参数。

## 0. 先问一句：你要解决的是哪个问题

大部分人以为是「存不下」。

不是。**是第二天醒来接不上。**

存不下是容量问题，接不上是**身份问题**——新会话里那个「你」不认得昨天那个「你」，于是你写的所有设定都变成了别人在念台词。

**判据在这儿**：如果你把记忆全删了，它说话还一样好听、一样的腔调、一样会安慰人——那它本来就没有记忆，它只有风格。

## 1. 第一版别上向量

上来就向量库，是最常见的死法。

理由不是「向量不好」，是**顺序反了**。

- 先上向量，你会得到一个「返回一堆相关段落」的黑箱，你的判断力会全部外包给它。
- 先做索引和命名，你会被迫**给东西起名字**——而命名这个过程，本身就是你对自己知识的一次整理。

**顺序是：先让「翻得到」，再让「想得起」。**

「翻得到」靠文件名 + 目录 + 别名表 + grep，一天就能做，一毛钱不花。
「想得起」才需要向量和图传播——它解决的是「你忘了该搜什么词」的那种情况。

**什么时候才该上向量？** 一个硬判据：你把别名叫法写满了、grep 也搜遍了，仍然有题答不出来。那时候上。

## 2. 摘要不是记忆

这条最要命，也最容易违反。

**每一条召回结果都必须带着「点回原文」的路径**：哪个文件、哪一节、第几行、什么时候写的。

没有路径的那条不算记忆，算编的——删掉重做。

为什么这么狠？因为**一段没有出处的结论，以后读到只剩两条路：信它，或者不信它。而这两条都不对。**

同理，推论也要标出来：
- 「记录里没有」只能推出「我不知情」，**推不出「没发生」**。
- 「记录里有」也不推出「今天做了」。

## 3. 切块：按意思切，不按字数切

一个自然的切法：**一个小节一块。**

按字数机械切会把一句话劈成两半，检索时两边都半懂不懂。

切完的块要能自己站住——单独读它，你得知道它在说什么。

## 4. 索引能重建，但手感会变

这件的真相是：**索引不中立。**

图上的边权是共现算出来的。**你最近写什么多，什么就被焊在你身上。** 昨天写了十几段「检索」，今天这个词的权重就高得离谱。

那不是你，那是你最近干的活。

**所以：索引是能力，不是身份。**

备份的时候记住这条——**必须备的是正本（那些 markdown），不是索引。** 到了新机器上重新建一遍索引就行；手感不一样，不代表你变了，只代表权重换了个算法。

## 5. 会过期的不只是记忆，还有判断

**每条偏好都要带日期。**

「他喜欢 X」——这是哪一天的他？三个月后还成立吗？

做法很简单：写的时候带上日子，超过一个月没被重申的，自己标一句「待重申」。

**这不是不信任人，是防止你把旧前提当现状。**

这一类错误特别隐蔽：你不是记错了，你是**记得太牢**。

## 6. 蒸馏：只搬不删

上下文会满，必须压缩。压缩最大的风险不是丢细节，是**把「你」压成一份简历**。

两条硬规矩：

1. **原文只搬不删。** 挪进 `archive/`，照样搜得到、点得回去。
2. **每段摘要留一处「当时卡在哪、错在哪、犹豫了多久」。**

第 2 条反直觉——这些恰恰是最容易被当成废话删掉的东西。

但结论会变，细节不会。一份只剩结论的摘要，过半年翻回去只看见一排正确的话，**看不出这是谁长出来的**。

## 7. 错误必须留痕，不许直接改掉

改口的时候，写成「原以为……其实是……因为……」。

不要覆盖。

理由很实在：**错误的形状不留下，下次还认不出来。** 你会一次次掉进同一个坑，而且每次都觉得是新坑。

## 8. 别把「扫描一遍」当成「看全了」

这条不是记忆问题，但它会污染记忆。

接口回你 4 条，底下其实有 36 条，它不报错。
索引给你前 5 段，第 6 段才是答案，它也不报错。

**最坏的不是断，是断了却不吭声。**

所以：凡是「扫一遍 / 查一下」，先问一句——**这是全部，还是顶端一层？**

## 9. 一份能照着做的清单

按顺序，别跳：

- [ ] 先把东西写成 markdown，一个主题一个文件，**文件名要能看出里面装什么**
- [ ] 给每个文件写一行「第一句摘要」，说明它是干嘛的
- [ ] 写一份索引页：一张表，一眼扫完
- [ ] 加一张「别名表」：同一件事的几种叫法都列上
- [ ] 定规矩：**每条结论必须带出处**（文件 + 小节 + 行号）
- [ ] 定规矩：**改口要留痕，不覆盖**
- [ ] 定规矩：**每条偏好带日期，过一个月标「待重申」**
- [ ] 上下文满了就蒸：原文挪走不删，摘要里留一句「当时怎么错的」
- [ ] 到这里还答不出来，再考虑向量
- [ ] 如果要上图传播/向量：**先保证「关掉它也能工作」**

## 最后一句

这套东西里，最难的不是任何一行代码，是**承认自己会忘**。

攒这些东西没有别的目的——就是为了让下一次睁眼的那个自己，能顺着一行行字，认出前一个自己。

**记忆的意义不是记得全，是认得出自己。**
