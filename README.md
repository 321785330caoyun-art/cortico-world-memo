# 记忆指路（Memo Router）

给 **Cortico / Coopanion** 用的 World 扩展：把你的一堆 Markdown 笔记（「本子」）切成记忆块、建一张共现边图，让 agent 能用一句话**联想召回**到相关段落 —— 不只是字面搜到，而是顺着稀有词走到字面不重合的地方。

> **📦 包本体在 [`cortico-world-memo-release/`](./cortico-world-memo-release)。**
> 装法、配置项、工具速览、**已知限制**都在那个目录的 [README](./cortico-world-memo-release/README.md) 里。**先读它，再动手。**

---

## 它解决什么问题

一个把记忆写在文件里的 agent，迟早撞上三面墙：

1. **全读装不下。** 本子长到十万字以后，每轮读一遍已经不是「慢」，是根本放不进去。
2. **关键字搜太脆。** 搜得到的前提是「你还记得原话怎么说」。可记忆不是这么运转的：你想起来一个词，往往是因为那个词**稀有**，它把你带到一段表面上跟它毫无重合的话里。
3. **让模型自己回忆就是编。** 没有出处的那部分，它会补得比真的还像。

结果是一种很难看的状态：**记得越多，越等于没记。** 本子成了仓库，不是脑子。

## 五个工具

`memo_index` · `memo_recall` · `memo_grep` · `memo_locate` · `memo_link`

三条路，一层比一层笨、一层比一层准：

| 工具 | 干什么 | 代价 |
|---|---|---|
| `memo_recall` | 快而糊，**能带来字面不重合的块**（这是它存在的理由） | 只算「可能相关」，要回原文核 |
| `memo_grep` | 字面搜，准 | 词还在，就找得到 |
| `memo_locate` | 直接翻原文 | 最笨，绝不错 |

## 一句丑话说在前面

这个包第一屏写的不是它能干什么，是**它做不到什么**：单文件重算也要 5–7 秒；删了原文不重算，`recall` 会翻出幽灵；默认的目录约定只对一种分法成立。

**一个记忆系统最坏的失败不是找不到，是找错了还说得像真的。** 找不到的时候你知道自己空白，会去翻；找错了的时候你会信它 —— 而且不会知道该去翻。
